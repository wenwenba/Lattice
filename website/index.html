BUILT FOR FLOW

专注记录，不切换语境。

从实时预览到全文检索、知识关联和可恢复删除，Lattice 把常用知识库动作收进同一个终端工作区。

01

编辑与预览，同屏发生

打开笔记即进入编辑。标题层级、表格、代码块、链接与图片在右侧实时呈现，窄屏也会自动调整布局。

```typescript const vault = await open('./notes') ```
02

普通目录就是 Vault

创建、重命名、移动与导入都在 CLI 内完成。笔记始终是普通 Markdown 文件，没有专有数据库。

~/notes/Projects/Launch.md
03

双向链接，把笔记连起来

输入 [[ 自动补全笔记；查看带上下文的反向链接，检查失效链接。重命名或移动笔记时同步更新指向它的 Wiki 链接。

WelcomeRoadmap随记
04

搜索 2.0，找到所需上下文

全文结果显示命中片段与高亮；支持短语、模糊标题，以及标签、路径、链接、日期筛选和排序。

/search"发布计划" tag:project sort:recent
05

删除可恢复，到期自动清理

/delete 先移入回收站，/trash 可恢复。保留期可选 7、30 或 90 天，默认 30 天；运行时定期清理，关闭后在下次启动时清理。

.lattice/trash/可恢复 · 默认保留 30 天
06

一个斜杠，调用所有动作

命令面板遵循 Claude Code 式输入体验，避开系统快捷键冲突，并支持中文界面。

/jot快速记录随记
/search搜索与筛选 Vault
/trash恢复删除的文件
