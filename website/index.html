BUILT FOR FLOW

专注记录，不切换语境。

从文件管理到实时预览，Lattice 把常用知识库动作收进同一个终端工作区。

01

编辑与预览，同屏发生

打开笔记即进入编辑。标题层级、表格、代码块、链接与图片在右侧实时呈现，窄屏也会自动调整布局。

```typescript const vault = await open('./notes') ```
02

普通目录就是 Vault

创建、重命名、移动、导入与删除都在 CLI 内完成。没有专有数据库，也没有迁移成本。

~/notes/Projects/Launch.md
03

链接、图片与反向链接

支持 Wiki Link、可点击超链接、Vault 内文件选择和剪贴板图片。附件跟随文档管理。

WelcomeRoadmap随记
04

一个斜杠，调用所有动作

命令面板遵循 Claude Code 式输入体验，避开系统快捷键冲突，并支持中文界面。

/jot快速记录随记
/search搜索 Vault
/summarizeAI 整理与汇总
